# BLE Virtual Device Simulator - Public Hub 📡

Welcome to the public repository for the **BLE Virtual Device Simulator** extension for VS Code and Open VSX, developed by CodeHorizon.

Although the core simulation engine's source code is private, this repository serves as a central hub for our community of users, engineering students, and developers. 

Whether you are prototyping connected devices via Wokwi, or developing cross-platform mobile applications (Flutter, React Native) that require hardware communication, this space is for you.

## 🎯 What is this repository for?

This repository is the official space to contribute to the extension's improvement:

* **🐛 Bug Reports (Issues):** Spotted an unexpected behavior on macOS or Linux? An issue with the Wokwi bridge? Open an issue and share your logs.
* **💡 Feature Requests:** Have an idea for a new default GATT profile or an interface enhancement? Propose it here.
* **💬 Discussions:** Ask architecture questions, share your IoT setups, or help other developers use the simulator.

## 🚀 Installation

The extension is publicly available on the following marketplaces:
* [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=CodeHorizon.ble-virtual-device-simulator)
* [Open VSX Registry](https://open-vsx.org/extension/CodeHorizon/ble-virtual-device-simulator) (Compatible with Antigravity, VSCodium, Cursor...)
